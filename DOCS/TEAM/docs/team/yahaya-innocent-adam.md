About Me
I am a member of the ProcessLink Ghana development team and a BSc Information Systems student. I looked after the code repository and the technical foundation.
My Understanding of the Project
ProcessLink Ghana is a web platform that funds processing machines such as cassava graters and palm fruit presses. It records who invested, who operated the machine, what customers paid and how revenue is shared, so each person can see where the money went.
My Contribution

* Set up sign in with roles so each user only sees their own workspace.
* Worked on the revenue split calculation and the automated tests for it.
* Connected deployment to Vercel so changes go live automatically.
* Worked on the Python analytics service used by the admin reports page.
